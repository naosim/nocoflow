# nocoflow
Nocode Work Flow System

## セットアップ
```
git clone https://github.com/naosim/nocoflow.git
cd nocoflow
npm install
```

## 起動
```
npm run dev
```

## プロジェクトの進め方
- プログラミングベースのフレームワークを作る
  - 呼ばれる関数内を実装すればOK
- 設定をUI上からできる状態にする

## ユースケース
- ドメインを選択する
- ユースケースを選択する


## 利用例：販売
- Domain: 商品
- Usecase: 注文
- Entity: 契約

- ## 利用例：課題管理
- Domain: 課題
- Usecase: 起票, 検討
- Entity: 課題票
